# Liquid Glass Monitor v1.0.0

First public release candidate of Liquid Glass Monitor, a hardware and system monitoring application for Windows.

## Features

- Real-time hardware and system monitoring.
- CPU, GPU, memory and storage monitoring.
- Network monitoring.
- Customizable translucent glass-inspired interface.
- Multimedia module.
- Portable Windows x64 application.

## Installation

1. Download the Windows x64 ZIP archive.
2. Extract the complete archive.
3. Run `LiquidGlassMonitor.exe`.

No traditional installation is required.

## Requirements

- Windows x64.
- .NET 10 Desktop Runtime x64 for the lightweight edition.
- No separate .NET installation for the self-contained edition.

Some hardware measurements may require administrator privileges or specific drivers.
