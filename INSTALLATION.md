## Français

### Configuration requise

- Windows 64 bits.
- Ordinateur compatible avec les API Windows utilisées par l'application.
- Aucun runtime .NET à installer pour la distribution autonome.

### Installation

Liquid Glass Monitor est distribué sous forme d'application portable.

1. Télécharger l'archive Windows x64.
2. Extraire intégralement le contenu du fichier ZIP dans un dossier.
3. Ouvrir le dossier `LiquidGlassMonitor`.
4. Lancer `LiquidGlassMonitor.exe`.

Aucune installation classique n'est nécessaire.

Ne pas déplacer l'exécutable indépendamment des autres fichiers :
les bibliothèques nécessaires doivent rester à ses côtés.

### Droits administrateur

Certaines mesures matérielles peuvent nécessiter des droits
administrateur ou des pilotes spécifiques.

Si une mesure n'est pas disponible, vérifier les permissions
et la compatibilité du matériel concerné.

### Désinstallation

Fermer l'application puis supprimer le dossier contenant
les fichiers extraits.

Aucune procédure de désinstallation particulière n'est nécessaire.

## English

### System requirements

- 64-bit Windows.
- A computer compatible with the Windows APIs used by the application.
- No separate .NET runtime installation required for the self-contained distribution.

### Installation

Liquid Glass Monitor is distributed as a portable application.

1. Download the Windows x64 archive.
2. Extract the entire ZIP archive into a folder.
3. Open the `LiquidGlassMonitor` folder.
4. Run `LiquidGlassMonitor.exe`.

No traditional installation is required.

Do not move the executable separately from the other files:
required libraries must remain alongside it.

### Administrator privileges

Some hardware measurements may require administrator
privileges or specific drivers.

If a measurement is unavailable, check permissions
and the compatibility of the relevant hardware.

### Uninstallation

Close the application and delete the folder
containing the extracted files.

No dedicated uninstallation procedure is required.
